Frequently Asked Questions

How long is OTP valid?

OTP expires after the configured expiry period (default 10 minutes).

Can I regenerate my API Key?

Yes. From the Clients page you can generate a new API Key.

Is HTTPS required?

Yes. PRAS only accepts secure HTTPS requests.
